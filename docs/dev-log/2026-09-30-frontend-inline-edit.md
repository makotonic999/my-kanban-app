# dev-log: 2026-09-30（フロント続き）— タスクのインライン編集（F2）

## この日やったこと
作成済みタスクのタイトル・期日を後から編集できるようにした。エクセルの F2 のように、
カード上でその場で編集する（モーダルなし）方式。

## 仕様
- **F2**: 選択中カードを編集モードに。タイトル入力へフォーカス＆全選択。
- タイトルで **↓ / Tab** → 期日編集へ。期日で **↑** → タイトルへ戻る。
- **Enter** 保存 / **Esc** 取消。ダブルクリックでも編集開始。
- 期日は既存と同じ `20260930` 形式（空欄で期日なし・不正日付はエラー）。
- 保存は**変更があったフィールドだけ** `PATCH /tasks/{id}` に送る。変更なしなら API を叩かず閉じる。

## 実装
- `frontend/src/api.ts`: `updateTask(id, { title?, due_date? })` を追加（既存 Update ハンドラを利用）。
- `frontend/src/components/Board.tsx`:
  - 編集状態 `editingId` / `editTitle` / `editDue` を追加。`startEdit` / `saveEdit` / `cancelEdit`。
  - グローバルキーハンドラに **F2** を追加。編集中はグローバル操作を抑止しカード側 onKeyDown に委譲。
  - `TaskCard` を編集モード対応に（タイトル/期日のインライン input、保存・取消ボタン、操作ヒント）。
- `keymap.ts` / `App.tsx`: ヘルプとフッターヒントに **F2 編集** を追記。

## 設計判断: 編集履歴は DB に残さない
- 状態遷移ログ（`task_status_events`）は「作業の流れ」の分析用でフェーズ6に直結。
- 一方タイトル/期日の編集履歴は監査ログ的な性質で、個人カンバンの年間振り返りには使わない。
- YAGNI により今は残さない。将来 undo/監査が要れば同型のテーブルを後付け可能。
