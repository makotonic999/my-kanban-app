### ボード（`components/Board.tsx`）
- ダーク化。列見出しにステータス色ドット + 件数バッジ。カードは選択時 `.neon-ring` で発光。

  プレースホルダ `例: 20260930 (2026/09/30)`。数字のみ・最大 8 桁。
  さらに 📅 ボタンで **カレンダーピッカー併用**（`showPicker()`、テキストと相互連動）。
- **各列を期日の近い順にソート**（期日なしは末尾、同日は id 昇順で安定）。表示順=キー選択順。
- 空カラムの「— 空 —」表示は撤去（すっきり）。

### キーボード操作（`keymap.ts`・`components/ShortcutsHelp.tsx`・Board の `useEffect`）
- 割り当ては `keymap.ts` に**案内定義を集約**（将来ユーザーがキーバインド切替できる布石）。
- `↑/↓`: 同列で選択移動。`←/→`: 隣列へ選択移動。`Shift+←/→`: 選択タスクを隣列へ移動
  （右端 Done は `completeTask`）。`N`: タイトルへフォーカス。`Delete/Backspace`: 削除（confirm）。
  `Esc`: 選択解除/モーダル閉じ。`?`: ショートカット一覧モーダル。
- 連続入力を優先しつつ、**入力欄で `↓` を押すとボード選択へ移れる**。ボード最上段で `↑` は入力欄へ戻る。

### 表示ヘルパー（`format.ts`・新規）
- `formatDueDate` / `isOverdue` / `parseYyyymmdd`（8 桁・存在しない日付は null）/
  `yyyymmddToInputValue` / `inputValueToYyyymmdd`。`formatEstimate` も残置（将来復活用）。

### 設計判断: 見積もり時間 UI の撤去
- 「タスク作成のたびに見積もり分を考えるのは負荷。カンバンは考え事を減らしたい」という気づき。
- 見積もりは**単体では価値が薄く、実績（actual）とセットで初めて効く**。今は実績記録 UI が無く宙に浮く。
- 判断: **見積もりを UI から撤去**（作成フォーム欄・カードの ⏱ 表示・Enter 送り）。
  型 / DB / API の `estimated_minutes` は**残置**（後方互換・将来復活可）。`createTask` は送らないだけ。
- 代わりに関心は「状態遷移の日時（In Progress / Done 入り）を**自動で**貯める」方向へ（下記）。

## 状態遷移日時について（調査メモ / 次の一手の土台）
- 現状スキーマで取れるのは `created_at` / `updated_at` / `completed_at`（Complete ハンドラで記録）/ `due_date`。
- **「Done 入りの時刻」は取れる**（`completed_at`。ただし再 Done で上書き、通常 Update 経由では入らない）。
- **「In Progress 入りの時刻」は取れない**（専用カラム無し。`updated_at` は上書きされ遷移を表さない）。
- フェーズ6（AI 年間振り返り）向けには、手入力の見積もりより**自動で貯まる遷移ログ**が筋が良い。
  - 案A: `tasks.started_at` を 1 本追加（軽い。サイクル/リードタイムは取れるが履歴は無し）。
  - 案B: `task_status_events`（履歴テーブル）を新設（全遷移をログ。滞在時間・差し戻し回数まで。AI 向き）。
  - いずれも DB スキーマ変更（マイグレーション）。既存データは壊さない後方互換の追加。
