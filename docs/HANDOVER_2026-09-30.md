## この日の成果（詳細）

### 1. フロント刷新（ダーク & モダン & クール）
- ディープネイビー背景 + ネオン系アクセント。`index.css` に `neon-text`/`neon-ring`/`glass`/`kbd`/`bg-grid`。

- dev-log: `docs/dev-log/2026-09-30-phase5-frontend-dark-keyboard.md`

### 2. キーボード操作（ドラッグは使わない方針）
- `↑↓` 同列で選択移動 / `←→` 隣列へ選択移動 / `Shift+←→` タスクを隣列へ移動（右端=Done=完了）。
- `N` 新規フォーカス / `Delete` 削除 / `Esc` 選択解除・モーダル閉じ / `?` ショートカット一覧。
- 入力欄で `↓` → ボード選択へ、ボード最上段で `↑` → 入力欄へ（連続入力と操作の両立）。
- 割り当ての案内は `frontend/src/keymap.ts` に集約（将来のユーザーカスタマイズの布石）。

### 3. 期日入力（`20260930` 形式 + カレンダー併用）
- テキストで 8 桁入力（プレースホルダ `例: 20260930 (2026/09/30)`）。📅ボタンでカレンダーも可（相互連動）。
- 各列を**期日の近い順**にソート（期日なしは末尾）。空カラムの「— 空 —」表示は撤去。
- 日付整形/パースは `frontend/src/format.ts`（`parseYyyymmdd` は存在しない日付を弾く）。

### 4. インライン編集（F2）
- `F2`（またはダブルクリック）で選択中カードをその場編集。タイトル→`↓/Tab`→期日、`Enter`保存/`Esc`取消。
- 既存 `PATCH /tasks/{id}` を利用（`api.ts` に `updateTask` 追加）。API 追加なし。
- dev-log: `docs/dev-log/2026-09-30-frontend-inline-edit.md`

### 5. 見積もり時間 UI の撤去（設計判断）
- 「作成のたびに見積もりを考えるのは負荷。カンバンは考え事を減らしたい」との判断で UI から撤去。
- 型/DB/API の `estimated_minutes` は**残置**（後方互換・将来復活可）。送らないだけ。

### 6. 状態遷移の自動記録（フェーズ6 下ごしらえ）★重要
- 新テーブル `task_status_events`（`task_id` / `from_status` / `to_status` / `changed_at`）+ index2本 + CASCADE。
- 記録: 作成時 `NULL→todo` / Update で status 実変化時 / Complete で `→done`（既doneは記録せず）。
- tasks 更新とイベント INSERT を**同一トランザクション**。更新前 status は `SELECT ... FOR UPDATE` で取得。
- 手入力の見積もりより「自動で貯まる客観ログ」を選んだ結果。リード/サイクルタイム・差し戻し回数の素材。
- dev-log: `docs/dev-log/2026-09-30-phase6-status-events.md`

### 7. プロダクト理解チュートリアル
- `docs/TUTORIAL.md`（503行）。フロント→API→認証→DB→SRE→インフラ→CI/CD を網羅的・順序的に解説。
- アーキテクチャ全体像と「1リクエストが辿る道」を最重点に。理解の入口として最初に読む想定。
