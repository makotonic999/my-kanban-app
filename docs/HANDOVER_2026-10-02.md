## 次回やること（決定済みの方針）: 実際に Web 公開する

[`docs/DEPLOY_FREE_TIER.md`](DEPLOY_FREE_TIER.md) に沿って、**ブラウザ操作で3サービスをセットアップ**する。
順番は **Neon → Render → Cloudflare**（後のサービスが前の URL を必要とするため）。

1. **Neon（DB）**: アカウント作成 → プロジェクト作成 → 接続文字列取得（`sslmode=require` 込み）
   → `db/schema.sql` を1回流す（psql か Neon の SQL エディタ）。
2. **Render（API）**: New → Blueprint → リポジトリ選択（`render.yaml` 検出）
   → 環境変数 `DATABASE_URL`（Neon）/`JWT_SECRET`/`CORS_ALLOWED_ORIGINS`（後で Cloudflare URL）を設定
   → API URL 発行（例 `https://my-kanban-api.onrender.com`）→ `/metrics` で疎通確認。
3. **Cloudflare Pages（フロント）**: リポジトリ連携 → **Root=`frontend` / build=`npm run build` / 出力=`dist`**
   → `VITE_API_BASE_URL`=Render の API URL → デプロイ → URL 発行（例 `https://xxx.pages.dev`）。
4. **配線仕上げ**: Render の `CORS_ALLOWED_ORIGINS` に Cloudflare の URL を設定（再デプロイ）。
5. **本番確認**: Cloudflare の URL でサインアップ→タスク作成まで。初回は Render のコールドスタートで数十秒待つ。

- 公開作業は**ブラウザ操作が主**（アカウント作成・環境変数入力）。アシスタントは設定値の判断・エラー対応を支援可能。
- **無料枠は変動するため、作業前に各サービスの料金ページで最新を確認**すること。
- 詰まったら画面/エラーを提示 → 一緒に解決。
